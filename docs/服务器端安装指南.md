## 方式一：本地开发环境（适合测试）

### 1. 安装依赖

```bash
cd server

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置文件

配置文件已存在：`server/config.yaml`

**重要配置项：**

```yaml
domains:
  api:
    url: "https://api.yourdomain.com"  # 你的域名或 IP
  allowed_origins:
    - "capacitor://localhost"  # 移动端（必须）
    - "http://localhost:3000"  # 开发环境
    - "*"  # 允许所有来源（仅开发环境）

database:
  type: "sqlite"  # 或 "postgresql"
  sqlite:
    path: "data/population.db"
```

### 3. 启动服务器

```bash
# 方式 1：直接运行（前台）
cd server
source venv/bin/activate
python app_modular.py

# 方式 2：使用 Gunicorn（生产环境）
gunicorn -w 3 -b 0.0.0.0:5000 app_modular:app
```

### 4. 访问测试

服务器启动后访问：
- **Web 界面**: http://127.0.0.1:5000
- **API 文档**: http://127.0.0.1:5000/api/
- **登录**: 用户名 `admin`，密码 `admin123`

**默认账户会在首次运行时自动创建。**

## 方式二：生产环境部署（推荐）

### 1. 系统要求

- **操作系统**: Ubuntu 20.04+ / CentOS 7+ / Debian 10+
- **Python**: 3.10+
- **内存**: 最低 1GB，推荐 2GB+
- **硬盘**: 最低 10GB

### 2. 安装系统依赖

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Python 和工具
sudo apt install -y python3 python3-pip python3-venv nginx

# 安装 PostgreSQL（可选，推荐用于生产环境）
sudo apt install -y postgresql postgresql-contrib

# 安装 Redis（可选，用于缓存）
sudo apt install -y redis-server
```

### 3. 配置数据库（PostgreSQL）

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库和用户
CREATE DATABASE population;
CREATE USER population_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE population TO population_user;
\q

# 修改配置文件 server/config.yaml
database:
  type: "postgresql"
  postgresql:
    host: "localhost"
    port: 5432
    database: "population"
    user: "population_user"
    password: "${DB_PASSWORD}"
```

### 4. 配置环境变量

创建 `.env` 文件：

```bash
cd server
cat > .env << 'EOF'
SECRET_KEY=your-secret-key-change-this
DB_PASSWORD=your-db-password
REDIS_PASSWORD=your-redis-password
EOF

# 设置权限
chmod 600 .env
```

**生成安全密钥：**

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

### 5. 配置 Systemd 服务

创建系统服务文件：

```bash
sudo tee /etc/systemd/system/population-api.service > /dev/null << 'EOF'
[Unit]
Description=Population Information System API
After=network.target postgresql.service

[Service]
Type=notify
User=www-data
Group=www-data
WorkingDirectory=/opt/population-system/server
Environment="PATH=/opt/population-system/server/venv/bin"
ExecStart=/opt/population-system/server/venv/bin/gunicorn \
  --workers 3 \
  --bind unix:population.sock \
  --timeout 120 \
  --access-logfile /var/log/population/access.log \
  --error-logfile /var/log/population/error.log \
  app_modular:app

[Install]
WantedBy=multi-user.target
EOF
```

启动服务：

```bash
# 创建日志目录
sudo mkdir -p /var/log/population
sudo chown www-data:www-data /var/log/population

# 启动服务
sudo systemctl daemon-reload
sudo systemctl enable population-api
sudo systemctl start population-api
sudo systemctl status population-api
```

### 6. 配置 Nginx 反向代理

```bash
sudo tee /etc/nginx/sites-available/population > /dev/null << 'EOF'
server {
    listen 80;
    server_name api.yourdomain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    # SSL 证书（使用 Let's Encrypt）
    ssl_certificate /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.yourdomain.com/privkey.pem;

    # SSL 配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 日志
    access_log /var/log/nginx/population_access.log;
    error_log /var/log/nginx/population_error.log;

    # 反向代理
    location / {
        include proxy_params;
        proxy_pass http://unix:/opt/population-system/server/population.sock;
        proxy_read_timeout 120s;
        proxy_connect_timeout 60s;
    }

    # 文件上传大小限制
    client_max_body_size 10M;

    # 静态文件
    location /static {
        alias /opt/population-system/server/web_static;
        expires 30d;
    }
}
EOF

# 启用站点
sudo ln -s /etc/nginx/sites-available/population /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重载 Nginx
sudo systemctl reload nginx
```

### 7. 配置 SSL 证书（Let's Encrypt）

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d api.yourdomain.com

# 自动续期
sudo systemctl enable certbot.timer
sudo systemctl start certbot.timer
```

## 方式三：Docker 部署（推荐）

### 1. 安装 Docker

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 添加当前用户到 docker 组
sudo usermod -aG docker $USER

# 启动 Docker
sudo systemctl enable docker
sudo systemctl start docker
```

### 2. 配置环境变量

```bash
cat > .env << 'EOF'
SECRET_KEY=your-secret-key-change-this
DB_PASSWORD=your-db-password
REDIS_PASSWORD=your-redis-password
EOF
```

### 3. 启动服务

```bash
# 构建并启动
docker-compose up -d

# 查看日志
docker-compose logs -f app

# 查看状态
docker-compose ps

# 停止服务
docker-compose down
```

### 4. 数据持久化

Docker 会自动创建数据卷：
- `population_data`: 数据库文件
- `population_uploads`: 上传文件
- `population_logs`: 日志文件

## 配置说明

### 1. 域名配置

编辑 `server/config.yaml`：

```yaml
domains:
  api:
    url: "https://api.yourdomain.com"
    enabled: true

  # 移动端 CORS（重要！）
  allowed_origins:
    - "capacitor://localhost"  # 移动端
    - "http://localhost"       # 本地调试
    - "https://yourdomain.com"  # 生产域名
```

### 2. 数据库切换

**SQLite（开发环境）：**

```yaml
database:
  type: "sqlite"
  sqlite:
    path: "data/population.db"
```

**PostgreSQL（生产环境）：**

```yaml
database:
  type: "postgresql"
  postgresql:
    host: "localhost"
    port: 5432
    database: "population"
    user: "population_user"
    password: "${DB_PASSWORD}"
    pool_size: 10
    max_overflow: 20
```

### 3. 安全配置

```yaml
security:
  secret_key: "${SECRET_KEY}"  # 从环境变量读取
  token_expiry: 7200           # Token 有效期 2 小时
  password_min_length: 6
  login_max_attempts: 5        # 最大登录失败次数
  login_lock_minutes: 15       # 锁定时长
```

## 常见问题

### 1. 端口被占用

```bash
# 查看端口占用
sudo lsof -i :5000

# 结束进程
sudo kill -9 <PID>
```

### 2. 权限问题

```bash
# 数据目录权限
sudo chown -R www-data:www-data data uploads logs

# 文件权限
chmod 600 server/config.yaml
chmod 600 server/.env
```

### 3. 数据库连接失败

```bash
# PostgreSQL 测试连接
sudo -u postgres psql -d population

# Python 测试
python3 -c "from sqlalchemy import create_engine; engine = create_engine('postgresql://user:pass@localhost/population'); print(engine.connect())"
```

### 4. SSL 证书问题

```bash
# 测试证书
sudo certbot certificates

# 续期证书
sudo certbot renew --dry-run
```

### 5. 日志查看

```bash
# 应用日志
tail -f logs/app.log

# Nginx 日志
tail -f /var/log/nginx/population_access.log

# Systemd 日志
sudo journalctl -u population-api -f
```

## 备份与恢复

### 1. SQLite 备份

```bash
# 备份
cp data/population.db backups/population_$(date +%Y%m%d).db

# 恢复
cp backups/population_20260812.db data/population.db
```

### 2. PostgreSQL 备份

```bash
# 备份
pg_dump -U population_user population > population_backup.sql

# 恢复
psql -U population_user population < population_backup.sql
```

### 3. 自动备份脚本

```bash
# 创建备份脚本
cat > /opt/population-system/backup.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/opt/population-system/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# 备份数据库
pg_dump -U population_user population > $BACKUP_DIR/db_$DATE.sql

# 备份上传文件
tar -czf $BACKUP_DIR/uploads_$DATE.tar.gz uploads/

# 删除 60 天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +60 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +60 -delete
EOF

chmod +x /opt/population-system/backup.sh

# 添加到 crontab（每天凌晨 2 点执行）
(crontab -l 2>/dev/null; echo "0 2 * * * /opt/population-system/backup.sh") | crontab -
```

## 安全加固

### 1. 防火墙配置

```bash
# 安装 UFW
sudo apt install ufw

# 允许必要端口
sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 启用防火墙
sudo ufw enable
```

### 2. SSH 安全

```bash
# 编辑 SSH 配置
sudo nano /etc/ssh/sshd_config

# 禁用 root 登录
PermitRootLogin no

# 使用密钥登录
PasswordAuthentication no

# 重启 SSH
sudo systemctl restart sshd
```

### 3. 定期更新

```bash
# 启用自动安全更新
sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades
```

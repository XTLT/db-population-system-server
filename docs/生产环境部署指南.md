# 生产环境部署指南

## 一、部署前准备

### 1.1 服务器要求

**最低配置**:
- CPU: 2核
- 内存: 4GB
- 硬盘: 40GB SSD
- 带宽: 5Mbps

**推荐配置**:
- CPU: 4核
- 内存: 8GB
- 硬盘: 100GB SSD
- 带宽: 10Mbps

### 1.2 软件要求

- 操作系统: Ubuntu 20.04+ / CentOS 7+ / Debian 10+
- Docker: 20.10+
- Docker Compose: 2.0+

### 1.3 域名准备

需要的域名：
- `api.yourdomain.com` - API 服务
- `files.yourdomain.com` - 文件服务（可选）
- `www.yourdomain.com` - Web 管理端（可选）

## 二、服务器环境配置

### 2.1 安装 Docker

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | bash

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 验证安装
docker --version
docker-compose --version
```

### 2.2 配置防火墙

```bash
# Ubuntu UFW
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw enable

# CentOS Firewalld
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --reload
```

### 2.3 配置时区

```bash
# 设置时区为东八区
sudo timedatectl set-timezone Asia/Shanghai
```

## 三、应用部署

### 3.1 获取项目

```bash
# 克隆项目（如果使用 Git）
git clone https://github.com/XTLT/db-population-system.git
cd db-population-system

# 或上传项目文件
scp -r db-population-system user@server:/home/user/
```

### 3.2 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑配置
nano .env
```

**必须修改的配置**:
```env
SECRET_KEY=<生成方法见下文>
DB_PASSWORD=<数据库密码>
REDIS_PASSWORD=<Redis密码>
```

生成 SECRET_KEY:
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

### 3.3 配置应用

```bash
# 复制生产环境配置
cp config.production.yaml server/config.yaml

# 编辑配置
nano server/config.yaml
```

**必须修改的配置**:
- `domains.api.url` - API 域名
- `domains.allowed_origins` - CORS 允许的来源
- 其他按需调整

### 3.4 SSL 证书配置

#### 方式一：自签名证书（测试环境）

```bash
# 证书会在首次运行时自动生成
```

#### 方式二：Let's Encrypt（生产环境推荐）

```bash
# 安装 certbot
sudo apt install certbot

# 生成证书
sudo certbot certonly --standalone -d api.yourdomain.com

# 证书位置
/etc/letsencrypt/live/api.yourdomain.com/fullchain.pem
/etc/letsencrypt/live/api.yourdomain.com/privkey.pem

# 复制到项目
sudo cp /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem certs/server.crt
sudo cp /etc/letsencrypt/live/api.yourdomain.com/privkey.pem certs/server.key

# 设置自动续期
sudo certbot renew --dry-run
```

### 3.5 初始化部署

```bash
# 添加执行权限
chmod +x deploy.sh

# 执行初始化
./deploy.sh --init
```

部署脚本会自动：
1. 创建必要的目录
2. 检查配置文件
3. 构建 Docker 镜像
4. 启动所有服务
5. 进行健康检查

## 五、数据备份

### 5.1 自动备份

系统每天凌晨 2 点自动备份数据，保留 60 天。

备份文件位置: `backups/`

### 5.2 手动备份

```bash
./deploy.sh --backup
```

### 5.3 数据恢复

```bash
./deploy.sh --restore
# 输入备份文件名进行恢复
```

### 5.4 数据迁移

从原项目迁移数据：

```bash
# 复制数据库
scp /path/to/old/population.db user@server:/home/user/db-population-system/data/

# 复制照片
scp -r /path/to/old/Photos user@server:/home/user/db-population-system/uploads/

# 重启服务
./deploy.sh --restart
```

## 六、监控和日志

### 6.1 日志位置

```
logs/
├── app.log           # 应用日志
├── access.log        # Nginx 访问日志
└── error.log         # Nginx 错误日志
```

### 6.2 查看日志

```bash
# 实时查看应用日志
tail -f logs/app.log

# 查看 Nginx 访问日志
tail -f logs/access.log

# Docker 日志
docker-compose logs -f --tail=100 app
```

### 6.3 健康检查

```bash
# API 健康检查
curl http://localhost:5000/api/health

# 数据库连接检查
docker-compose exec db pg_isready -U postgres

# Redis 连接检查
docker-compose exec redis redis-cli -a <password> ping
```

## 七、性能优化

### 7.1 数据库优化

```sql
-- 连接数据库
docker-compose exec db psql -U postgres -d population

-- 查看连接数
SELECT count(*) FROM pg_stat_activity;

-- 创建索引（如果不存在）
CREATE INDEX IF NOT EXISTS idx_person_name ON person(name);
CREATE INDEX IF NOT EXISTS idx_person_id_card ON person(id_card);
```

### 7.2 Redis 优化

```bash
# 查看 Redis 内存使用
docker-compose exec redis redis-cli -a <password> info memory

# 清空缓存
docker-compose exec redis redis-cli -a <password> FLUSHALL
```

### 7.3 系统资源监控

```bash

# 查看磁盘使用

# 查看内存使用
```

## 八、安全加固

### 8.1 系统安全

```bash
# 禁用 root SSH 登录
sudo sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo systemctl restart sshd

# 安装 fail2ban
sudo apt install fail2ban
sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

### 8.2 应用安全

1. **修改默认密码**
   - 登录后立即修改 admin 密码

2. **定期更新密钥**
   ```bash
   # 更新 SECRET_KEY
   nano .env
   ./deploy.sh --restart
   ```

3. **启用 HTTPS**
   - 生产环境必须使用 HTTPS
   - 配置 SSL 证书

## 九、故障排查

### 9.1 服务无法启动

```bash
# 检查容器状态
docker-compose ps

# 查看容器日志
docker-compose logs app

# 检查端口占用
sudo netstat -nltp | grep 5000
```

### 9.2 数据库连接失败

```bash
# 检查数据库容器
docker-compose ps db

# 查看数据库日志
docker-compose logs db

# 测试连接
docker-compose exec app python -c "import psycopg2; ..."
```

### 9.3 Redis 连接失败

```bash
# 检查 Redis 容器
docker-compose ps redis

# 测试连接
docker-compose exec redis redis-cli -a <password> ping
```

### 9.4 API 请求超时

检查项：
1. 数据库查询是否优化
2. Redis 缓存是否生效
3. 服务器资源是否充足
4. 网络连接是否正常


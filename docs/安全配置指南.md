# 安全配置指南

## 概述

本文档记录人口通的安全配置，包括密码存储、证书固定、访问控制等内容。

---

## 一、密码安全

### 1.1 密码存储算法

系统使用 **Argon2id** 算法存储密码，这是目前最安全的密码哈希算法之一。

**配置参数**:

| 参数 | 值 | 说明 |
|------|-----|------|
| time_cost | 3 | 迭代次数 |
| memory_cost | 65536 | 内存成本 (64MB) |
| parallelism | 4 | 并行度 |
| hash_len | 32 | 哈希长度 |
| salt_len | 16 | 盐值长度 |

**密码格式**:

```
argon2:$argon2id$v=19$m=65536,t=3,p=4$<salt>$<hash>
```

### 1.2 密码策略

| 规则 | 要求 |
|------|------|
| 最小长度 | 8 位 |
| 字符要求 | 必须包含字母和数字 |
| 历史密码 | 不允许使用最近 5 次密码 |
| 默认密码 | `admin123`（首次登录强制修改）|

### 1.3 密码验证兼容性

系统支持两种密码格式：

| 格式 | 说明 | 验证方式 |
|------|------|---------|
| Argon2 | 新格式 | `argon2-cffi` 库验证 |
| SHA256 | 旧格式（兼容） | 双重 SHA256 验证 |

**自动迁移**: 用户通过网页登录时，旧密码会自动迁移为 Argon2 格式。

### 1.4 密码相关依赖

```bash
pip install argon2-cffi>=23.1.0
```

## 二、证书固定（Certificate Pinning）

> ⚠️ **重要**: 证书文件包含私钥，请妥善保管，**不要上传到代码仓库**！

### 2.1 推荐方案：一证多用

生成一次证书，部署到所有服务器和客户端。避免每次部署新服务器都重新打包客户端。

### 2.2 部署步骤

**步骤 1: 生成证书**

```bash
python cert_manager.py generate
```

**步骤 2: 备份证书到安全位置**

```bash
# 备份到本地目录（建议：U盘、移动硬盘或私有云盘）
python cert_manager.py backup ~/population-certs

# ⚠️ 不要上传到 GitHub！
```

**步骤 3: 导出到客户端（只需一次）**

```bash
python cert_manager.py export --all
```

**步骤 4: 构建 Mobile APP**

```bash
cd mobile
flutter build apk
```

**步骤 5: 部署到其他服务器**

```bash
# 从备份恢复证书
python cert_manager.py restore ~/population-certs

# 或直接部署到远程服务器
python cert_manager.py deploy user@server:/path/to/data/certs
```

### 2.3 证书管理命令

| 命令 | 说明 |
|------|------|
| `python cert_manager.py generate` | 生成新证书 |
| `python cert_manager.py backup /path` | 备份证书 |
| `python cert_manager.py export --all` | 导出到客户端 |
| `python cert_manager.py restore /path` | 从备份恢复 |
| `python cert_manager.py deploy user@host:/path` | 部署到远程服务器 |
| `python cert_manager.py status` | 查看证书状态 |

### 2.4 验证方式

| 客户端 | 有证书 | 无证书 |
|--------|--------|--------|
| Desktop | 证书固定验证 ✓ | 跳过验证 ⚠️ |
| Mobile | 证书固定验证 ✓ | 跳过验证 ⚠️ |

### 2.5 安全机制

- **证书固定**：客户端只信任指定的证书
- **一证多用**：同一证书可部署到所有服务器
- **10年有效期**：减少证书更新频率
- **私钥保护**：私钥文件权限 600，不上传代码仓库

### 2.6 备份建议

证书备份建议保存在：
- U盘或移动硬盘
- 私有云盘（非公开）
- 本地加密存储

**绝对不要**：
- 上传到 Git 仓库
- 发送到公共邮箱
- 分享给无关人员

## 三、访问控制

### 3.1 认证机制

| 机制 | 说明 |
|------|------|
| Token 存储 | 数据库存储（SHA256 哈希）|
| Token 有效期 | 2 小时（可配置）|
| 并发会话限制 | 单用户最多 2 个设备 |
| 登录失败锁定 | 5 次失败后锁定 15 分钟 |
| IP 速率限制 | 60 秒内最多 10 次登录尝试 |

### 3.2 角色权限

| 角色 | 权限 |
|------|------|
| admin | 所有操作、用户管理、系统配置 |
| user | 查看、编辑人员信息、导入导出 |

### 3.3 敏感操作限制

| 操作 | 限制 |
|------|------|
| 密码修改 | 60 秒内最多 5 次 |
| 密码重置 | 60 秒内最多 5 次 |
| 批量删除 | 单次最多 100 条，需确认 |
| 批量更新 | 单次最多 200 条，字段白名单 |

## 四、数据安全

### 4.1 文件上传限制

| 限制 | 值 |
|------|-----|
| 最大文件大小 | 16 MB |
| 允许的图片类型 | .jpg, .jpeg, .png, .bmp |
| 文件名过滤 | 移除特殊字符 |

### 4.2 备份加密

备份数据使用 AES-256-GCM 加密：

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
```

### 4.3 数据库安全

- SQLite 数据库文件权限: 600
- 敏感数据（Token）存储哈希值
- 操作日志记录所有敏感操作

## 六、环境变量配置

### 6.1 安全相关环境变量

```bash
# 密码哈希盐值（自动生成）
# .token_salt 文件

# 默认管理员密码
DEFAULT_ADMIN_PASSWORD=your_secure_password

# Flask 密钥
SECRET_KEY=your_secret_key

# 调试模式（生产环境禁用）
FLASK_DEBUG=0

# CORS 允许的源
CORS_ORIGINS=https://your-domain.com:5000
```

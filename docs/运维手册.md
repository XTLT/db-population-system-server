# 系统运维手册

## 一、日常运维任务

### 1.1 每日检查（5分钟）

```bash
# 查看服务状态
./deploy.sh --status

# 检查磁盘空间
df -h

# 检查错误日志
tail -50 logs/app.log | grep ERROR
```

### 1.2 每周检查（30分钟）

```bash
# 1. 系统资源使用情况
docker stats --no-stream

# 2. 数据库大小
docker-compose exec db psql -U postgres -d population -c "SELECT pg_size_pretty(pg_database_size('population'));"

# 3. Redis 内存使用
docker-compose exec redis redis-cli -a <password> info memory

# 4. 备份文件检查
ls -lh backups/

# 5. 日志文件大小
du -sh logs/*

# 6. 应用错误统计
grep -c ERROR logs/app.log
```

### 1.3 每月检查（1小时）

```bash
# 1. 系统更新
sudo apt update && sudo apt upgrade

# 2. Docker 清理
docker system prune -f

# 3. 数据库优化
docker-compose exec db psql -U postgres -d population -c "VACUUM ANALYZE;"

# 4. Redis 内存优化
docker-compose exec redis redis-cli -a <password> MEMORY PURGE

# 5. 日志归档
tar -czf logs_$(date +%Y%m).tar.gz logs/
rm logs/*.log

# 6. SSL 证书检查
openssl x509 -enddate -noout -in certs/server.crt
```

## 二、监控指标

### 2.1 系统监控

| 指标 | 正常范围 | 告警阈值 | 检查命令 |
|------|---------|---------|---------|
| CPU 使用率 | < 70% | > 90% | `top` |
| 内存使用 | < 80% | > 90% | `free -h` |
| 磁盘使用 | < 80% | > 90% | `df -h` |
| 网络流量 | 正常 | 异常波动 | `iftop` |

### 2.2 应用监控

| 指标 | 检查方式 | 频率 |
|------|---------|------|
| API 响应时间 | `curl -w "%{time_total}"` | 实时 |
| 请求成功率 | Nginx 日志统计 | 每日 |
| 数据库连接数 | `pg_stat_activity` | 实时 |
| Redis 内存 | `info memory` | 实时 |

### 2.3 业务监控

```bash
# 用户数量
docker-compose exec db psql -U postgres -d population -c "SELECT count(*) FROM users;"

# 人员数量
docker-compose exec db psql -U postgres -d population -c "SELECT count(*) FROM person;"

# 今日操作次数
docker-compose exec db psql -U postgres -d population -c "SELECT count(*) FROM operation_log WHERE DATE(timestamp) = CURRENT_DATE;"

ls -1 uploads/Photos/ | wc -l
```

## 四、故障处理

### 4.1 服务宕机

**症状**: 无法访问 API

**处理步骤**:
```bash
# 1. 检查容器状态
docker-compose ps

# 2. 查看日志
docker-compose logs --tail=100 app

# 3. 重启服务
./deploy.sh --restart

# 4. 如果重启失败，检查配置
nano server/config.yaml
nano .env

# 5. 重新构建
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

### 4.2 数据库故障

**症状**: 数据库连接失败

**处理步骤**:
```bash
# 1. 检查数据库容器
docker-compose ps db

# 2. 查看数据库日志
docker-compose logs db

# 3. 测试连接
docker-compose exec db pg_isready -U postgres

# 4. 如果数据库损坏，恢复备份
./deploy.sh --restore
```

### 4.3 磁盘空间不足

**症状**: 无法上传文件，服务异常

**处理步骤**:
```bash
# 1. 查看磁盘使用
df -h

# 2. 查找大文件
du -h --max-depth=1 / | sort -hr | head -10

# 3. 清理日志
find logs/ -name "*.log" -mtime +30 -delete

# 4. 清理 Docker
docker system prune -f

# 5. 清理旧备份
find backups/ -type f -mtime +60 -delete
```

### 4.4 内存不足

**症状**: 服务响应慢，OOM

**处理步骤**:
```bash
# 1. 查看内存使用
free -h

# 2. 查看进程内存
ps aux --sort=-%mem | head

# 3. 重启 Redis
docker-compose restart redis

# 4. 清理 Redis 内存
docker-compose exec redis redis-cli -a <password> FLUSHALL

# 5. 重启应用
docker-compose restart app
```

SELECT query, calls, total_time, mean_time
FROM pg_stat_statements
ORDER BY total_time DESC
LIMIT 10;

-- 创建缺失的索引

# 查看缓存命中率

## 六、安全管理

### 6.1 密码管理

```bash
# 修改 admin 密码
# 登录 Web 界面修改

# 修改数据库密码
docker-compose exec db psql -U postgres
ALTER USER postgres WITH PASSWORD 'new_password';
# 更新 .env 文件

# 修改 Redis 密码
# 更新 .env 和 docker-compose.yml
./deploy.sh --restart
```

### 6.2 访问控制

```bash
# 查看 API 访问日志
grep "api.yourdomain.com" logs/access.log

# 查看失败登录
grep "登录失败" logs/app.log

# 封禁 IP（如有攻击）
sudo ufw deny from <IP>
```

### 6.3 SSL 证书更新

```bash
# Let's Encrypt 自动续期
sudo certbot renew

# 手动更新证书
sudo certbot certonly --standalone -d api.yourdomain.com

# 复制新证书
sudo cp /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem certs/server.crt
sudo cp /etc/letsencrypt/live/api.yourdomain.com/privkey.pem certs/server.key

# 重启 Nginx
docker-compose restart nginx
```

| 用户数 | 数据库 | Redis | 存储 | 带宽 |
|--------|--------|-------|------|------|

- CPU 使用率持续 > 70%

## 八、日志管理

### 8.1 日志轮转

```bash
# 配置 logrotate
sudo tee /etc/logrotate.d/population <<EOF
/path/to/population-system/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0640 root root
}
EOF
```

### 8.2 日志分析

```bash
# 统计今日请求数
grep "$(date +%Y-%m-%d)" logs/access.log | wc -l

# 统计错误数
grep ERROR logs/app.log | wc -l

# 查看最频繁的请求
awk '{print $7}' logs/access.log | sort | uniq -c | sort -rn | head -10
```

### 9.1 定时任务

```bash

crontab -e

# 添加任务
0 2 * * * /path/to/deploy.sh --backup           # 每天凌晨2点备份
0 3 * * 0 docker system prune -f                # 每周清理Docker
0 4 1 * * ./deploy.sh --backup >> backup.log    # 每月异地备份
```

### 9.2 监控脚本

```bash
#!/bin/bash
# health_check.sh

# 检查服务健康
if ! curl -f http://localhost:5000/api/health > /dev/null 2>&1; then
    echo "Service unhealthy, restarting..."
    ./deploy.sh --restart
fi

# 检查磁盘空间
DISK_USAGE=$(df -h | grep -vE '^Filesystem|tmpfs|cdrom' | awk '{print $5}' | head -1 | sed 's/%//')
if [ "$DISK_USAGE" -gt 80 ]; then
    echo "Disk usage: ${DISK_USAGE}%"
    # 发送告警
fi
```

## 十二、常用命令速查表

```bash
# 系统监控
top                    # CPU/内存
df -h                  # 磁盘
free -h                # 内存
iftop                  # 网络

# Docker
docker ps              # 容器列表
docker stats           # 资源监控
docker logs <container> # 日志
docker exec -it <container> bash # 进入容器

# 服务管理
./deploy.sh --status   # 状态
./deploy.sh --logs     # 日志
./deploy.sh --restart  # 重启

# 数据库
psql -U postgres -d population  # 连接
pg_dump > backup.sql  # 备份
psql < backup.sql     # 恢复

# Redis
redis-cli -a <password>  # 连接
redis-cli info         # 信息
redis-cli FLUSHALL     # 清空

# 日志
tail -f logs/app.log   # 实时日志
grep ERROR logs/app.log # 错误日志
```
